# Resume Filler

Python browser automation for job search, application preparation, and review workflows.

## Technology

Python, Playwright.

## Run locally

Use Python 3.10 or later. Create a virtual environment, install `requirements.txt`, and install the Playwright browser with `python -m playwright install chromium`. Fill in your own local `src/profile.py` template before running `python main.py --help`. Configure only the integrations you intend to use. Inspect and review the workflow before submitting applications.

## Portfolio snapshot

This repository contains a source snapshot of a personal project. Personal records, credentials, browser sessions, local databases, and generated output are excluded. Use your own configuration and fictional data when evaluating it. Some integrations require external accounts or additional setup. This is a development project, with feature limitations documented in the source and guides.
